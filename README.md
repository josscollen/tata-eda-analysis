# Tata GenAI Data Analytics — Geldium Finance Project

## Overview
Completed a 3-part data analytics project for Geldium Finance as an AI Transformation Consultant at Tata iQ. The project focused on predicting credit card delinquency using AI/ML techniques.

## Project Structure

### Task 1: Exploratory Data Analysis (EDA)
- Analyzed 500 customer records across 19 variables
- Identified missing data patterns (Income: 39 missing, Loan Balance: 29 missing)
- Discovered key risk indicators and data quality issues
- Created visualizations showing delinquency patterns

### Task 2: Predictive Model Framework
- Selected Logistic Regression as the primary model
- Justified choice based on interpretability, dataset size, and business alignment
- Defined evaluation strategy with 5 key metrics (Accuracy, Precision, Recall, F1, AUC-ROC)
- Planned bias detection across employment, location, and card type

### Task 3: Business Report for Collections Strategy
- Translated technical findings into business recommendations
- Identified top 3 risk factors: Business cards (21.3%), Unemployed (19.4%), LA location (19.6%)
- Created SMART recommendation for Business Card Financial Wellness Program
- Addressed ethical considerations and responsible AI principles

## Key Findings
- 16% of customers are delinquent (80 out of 500)
- Business card holders: 21.3% delinquency (highest)
- Unemployed customers: 19.4% delinquency
- Los Angeles: 19.6% delinquency (highest region)
