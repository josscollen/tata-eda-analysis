# Tata GenAI Data Analytics — EDA Project

## Overview
Exploratory Data Analysis on Geldium Finance's customer dataset to identify delinquency risk factors using AI-powered insights.

## Project Details
- **Program:** Tata GenAI Powered Data Analytics (Forage)
- **Role:** AI Transformation Consultant
- **Dataset:** 500 customers, 19 variables
- **Goal:** Identify risk factors for credit card delinquency

## Key Findings
- **16% of customers** are delinquent (80 out of 500)
- **Missed Payments** is the strongest predictor of delinquency
- **Credit Utilization** above 50% correlates with higher delinquency
- **Debt-to-Income Ratio** is significantly higher in delinquent group
- **Missing data** found in Income (7.8%), Loan_Balance (5.8%), Credit_Score (0.4%)
